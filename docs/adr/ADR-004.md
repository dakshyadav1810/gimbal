# ADR-004: Observed page snapshots

**Status:** Accepted

## Context

A test-writing agent that cannot see the app guesses at labels and roles. Static analysis of the front-end source was tried and removed: it only worked for one framework, went stale, and could disagree with the page that actually renders.

## Decision

Give agents one tool, `getPage`, that returns a **snapshot of what Gimbal actually observed** in a browser: roles, accessible names, regions, test ids and disabled state, with a capture time, whether the browser was logged in, and a DOM fingerprint. Snapshots are captured while grounding and on request, kept as the latest three per page, and never contain input values, URL query strings or fragments, or ARIA text.

Every response states that it is one observation and that states nobody visited are absent.

## Consequences

- Works for any framework; costs one page load.
- It can be out of date or miss states. It is a hint; grounding on the live page decides.
- Nothing in it can leak a typed secret.
