# ADR-003: One language: TypeScript on Node

**Status:** Accepted

## Context

The product needs a browser driver (Playwright), a local server, a CLI, an MCP server, a dashboard, and one shared definition of the test format. Using several languages would mean duplicating that format and shipping several runtimes.

## Decision

TypeScript on Node 22 for everything, as a pnpm workspace built with Turborepo. Schemas are written once in Zod (`packages/shared`) and imported by every package. The server is Fastify, storage is SQLite (better-sqlite3 with Drizzle) plus JSON files, and the dashboard is a Vite single-page app served by the core process.

## Consequences

- One install, one runtime, one set of types end to end.
- Playwright is first-class.
- Node 22 or newer is required.
